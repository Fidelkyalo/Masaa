# MASAA Mobile Application

Intelligent Scheduling & Time Management On The Go for iOS & Android.

## Features Included
- 📱 **Mobile Touch Dashboard**: Quick stats, natural language prompt scheduler, today's agenda.
- 📅 **Mobile Calendar Screen**: Touch date selector, event cards, and attendee chips.
- 🔗 **Smart Booking Link**: Mobile availability slot picker & shareable link builder.
- 📋 **Tasks & Priorities**: Touch-enabled checklist with priority badges.
- 👤 **Profile & Settings**: Timezone selection, REST API status indicator, and plan badge.
- ⚡ **REST API Connected**: Synchronizes live with the Phase 2 backend REST API (`http://localhost:5000/api/v1`).

## Setup & Run
```bash
npm install
npm start
```
